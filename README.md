# Pagrysha VPN Website

Официальный сайт для Pagrysha VPN с глубокой поддержкой OLED темы, минималистичным Ч/Б логотипом в виде груши и полной адаптацией для навигации пультом ДУ на Android TV.

## Содержимое сборки

- `assets/downloads/Pagrysha_VPN_v8a.apk` — Версия для 64-битных смартфонов Android (ARM64-v8a)
- `assets/downloads/Pagrysha_VPN_v7a.apk` — Версия для 32-битных смартфонов Android (ARMv7)
- `assets/downloads/Pagrysha_VPN_TV.apk` — Специальная версия для Android TV / Google TV с D-Pad навигацией

## Особенности сайта
- **OLED Dark Theme**: Глубокий черный цвет (`#000000`) для экономии заряда батареи и максимального контраста.
- **Минималистичный Ч/Б логотип**: Векторная лаконичная груша в высоком разрешении.
- **TV Remote Navigation (D-Pad)**: Полная поддержка физических кнопок стрелок, Enter, Space и пульта ДУ.
- **Адаптивность**: Мобильные смартфоны, планшеты, десктоп и ТВ-экраны.
